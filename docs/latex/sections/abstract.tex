This thesis presents a comprehensive real-time face recognition system designed for security, attendance tracking, and user authentication applications. The system integrates multiple state-of-the-art face detection models (MediaPipe and YOLOv8), robust face recognition using FaceNet embeddings, and multiple verification metrics to ensure high accuracy and performance.

Key features of the implemented system include a flexible configuration framework, support for different face detection algorithms, face alignment for improved recognition accuracy, drowsiness detection capabilities, and a user-friendly API with web interface. The system is designed with modularity and extensibility in mind, allowing for easy integration of new models and features.

Experimental results demonstrate the system's effectiveness across various lighting conditions and scenarios, with high verification accuracy and real-time processing capabilities on standard hardware. This work contributes to the field by providing a comprehensive, production-ready face recognition implementation that balances accuracy, speed, and usability.
