This thesis presents a comprehensive implementation of a real-time face recognition system that combines multiple face detection models, recognition techniques, and verification methodologies. The system is designed with modularity, configurability, and performance in mind, making it suitable for both research and practical applications.

The implementation features a flexible architecture that supports multiple face detection approaches (MediaPipe, YOLOv8, YOLOv8 ONNX), facial landmark detection, face alignment, and drowsiness detection. It utilizes FaceNet embeddings for face recognition and supports multiple verification metrics including cosine similarity, Euclidean distance, and L2-normalized Euclidean distance.

A key contribution of this work is the development of a centralized configuration system that allows for easy parameter tuning and customization without code modification. The system supports various operational modes including camera-based real-time processing, single image analysis, and a web-based API interface.

Experimental results demonstrate the system's effectiveness in accurately identifying faces in challenging conditions with reasonable computational requirements. The project provides a solid foundation for applications in security, attendance systems, and human-computer interaction scenarios.
